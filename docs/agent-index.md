# Agent Index

Use this file first when starting assignment.

## Best context order

1. `docs/assignment-context.md`
2. `docs/architecture/overview.md`
3. `docs/decisions/`
4. `plan_to_do/*.md`
5. `.omo/specs/*.md`
6. `.omo/interviews/*.md`

## What each source gives

- `docs/assignment-context.md`: current project scope, owner, status, links.
- `docs/architecture/overview.md`: system map, modules, data flow.
- `docs/decisions/`: why choices exist.
- `plan_to_do/`: execution plan and atomic backlog.
- `.omo/specs/` and `.omo/interviews/`: requirement history.

## Agent rule

- Verify assignment context here before new implementation.
- If docs conflict, follow latest dated plan/spec and open ADRs.
